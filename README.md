## TASK-1

**Exploratory Data Analysis (EDA) Summary:**
The EDA focuses on the PhysioNet EEG Motor Movement/Imagery Database (EEGMMIDB). The analysis includes 109 subjects with 64 EEG channels sampled at 160 Hz. The data explores motor execution runs (left/right fist) and motor imagery runs to understand patterns across subjects and tasks. The EDA involves filtering, epoching, and visualizing EEG signals to prepare for downstream machine learning tasks.
